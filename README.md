# GRH — téléchargements

**GRH** est l'application Windows de gestion des ressources humaines : personnel, présences et pointeuses, congés,
paie, badges et documents RH, pensée pour les entreprises de Madagascar.

Ce dépôt ne contient que les versions publiées de l'application.

## Télécharger

Dernière version, toujours à la même adresse : **[grh-setup.exe](https://github.com/herilalainafnc-ui/GRH-releases/releases/latest/download/grh-setup.exe)**.

Notes de version et anciennes versions : [toutes les versions](../../releases).

## Installer

1. Ouvrez le fichier téléchargé (`grh-setup.exe`, ou `grh-<version>-setup.exe` pour une version précise).
2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur **Informations complémentaires**, puis sur
   **Exécuter quand même**. Cet avertissement vient de ce que l'installateur n'est pas encore signé numériquement.
3. Suivez l'assistant : aucun droit d'administrateur n'est nécessaire.

Une version déjà installée est simplement mise à jour : vos réglages sont conservés, et vos données ne bougent pas
(elles sont enregistrées sur nos serveurs, pas sur l'ordinateur).

**Configuration requise** : Windows 10 ou Windows 11, 64 bits, et une connexion Internet.

## Essai et abonnement

Chaque entreprise utilise toute l'application gratuitement pendant 30 jours. L'abonnement se règle ensuite par carte
Visa, depuis l'application (Compte › Abonnement).
